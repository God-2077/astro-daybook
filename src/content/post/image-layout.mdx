正文里的图片不用加任何标记，`src/lib/markdown-pipeline.ts` 会按写法决定它是独占一块，还是和同一行的图片并排。下面用同一张封面把几种情况都排一遍。

## 一张图

图片独占一行时，会带一圈细边框，图注取自 `alt`：

```markdown
![1920x1080](https://dummyimage.com/1920x1080)
```

![1920x1080](https://dummyimage.com/1920x1080)

## 图片紧跟在文字后面

图片与文字之间不必空行。只要图片独占一行，它照样会单独成块，不会挤在段落里：

这一句的下一行紧接着图片，中间没有空行
![封面 · 紧跟文字](https://dummyimage.com/1920x1080)

## 同一行并排

同一行里用空格隔开，两张图并排显示，各自保留边框与图注：

```markdown

```

![并排 · 左](https://dummyimage.com/1920x1080) ![并排 · 右](https://dummyimage.com/1920x1080)

## 不写图注

## 插图组件

用 `Figure` 组件代替 Markdown 图片语法：图片先 `import` 进来，再交给组件生成与正文一致的图框。或者直接传入图片 URL。

但 `Figure` 组件不支持并排显示。想并排显示，只能用 Markdown 图片语法，或者用表格包裹。

```jsx
import { Figure } from '@ui';
import myImage from '/public/images/BV1tUxy6BEGV.webp';
export const imgurl = "https://k-pan.edgeone.ksable.top/public/astro-daybook/images/nya.webp";

<Figure src={myImage} alt="被巨大幽灵袭击了…♡" />
<Figure src={imgurl} alt="吃药大王喵" />

<table width="100%" align="center">
  <tr>
    <td align="center"><Figure src={myImage} alt="被巨大幽灵袭击了…♡" /></td>
    <td align="center"><Figure src={imgurl} alt="吃药大王喵" /></td>
  </tr>
</table>
```
