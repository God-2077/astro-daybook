这篇文章本身就是 `.mdx`：它和普通文章共用 frontmatter、列表页与 RSS，只是正文多了一点组件能力。

## 表达式与图片

MDX 表达式会在构建期求值，例如今天是 {new Date('2026-10-28T00:00:00+08:00').getFullYear()} 年。

![MDX 示例图片](/images/demo/diary-line.svg)

> 组件、表达式和普通 Markdown 可以混排；渲染结果仍然落在 `.a-prose` 的纸页排版里。

## 使用方式

在 `src/content/post/` 或 `src/content/daily/` 下新建 `.mdx` 文件即可；独立页面放在 `src/content/pages/`，由 `src/pages/[...page].astro` 自动套 `PageLayout`，不需要写 `layout`。

```mdx
import { Timeline, TimelineItem } from '@ui';

<Timeline>
  <TimelineItem date="2026-10-24" title="标题">
    正文支持 **Markdown**。
  </TimelineItem>
</Timeline>
```
