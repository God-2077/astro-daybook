## テキスト装飾

- **太字（強調）**
- *斜体（イタリック）*
- ***太字 + 斜体***
- ~~打ち消し線~~
- `インラインコード`
- 通常のテキストと**強調**の混在
- 特殊文字のエスケープ：\*アスタリスク\*、\`バッククォート\`、\_アンダースコア\_

## コードブロック

インラインコードは `console.log("こんにちは")` のように書きます。

```javascript
// JavaScript のサンプル
const greet = (name) => {
  console.log(`こんにちは、${name}さん！`);
};

greet("田中");
```

```python
# Python のサンプル
def fibonacci(n: int) -> list[int]:
    """フィボナッチ数列を返す"""
    result = [0, 1]
    while len(result) < n:
        result.append(result[-1] + result[-2])
    return result[:n]


print(fibonacci(10))
```

長文テスト

日本語は単語の区切りにスペースを入れないため、長い文章がどのように折り返されるかを確認する必要があります。たとえば、この段落は意図的に長めの文章を続けていますが、ブラウザの幅に応じて自動的に折り返されるはずです。句読点（、。）や括弧（「」）が行頭に来ないような禁則処理は、Markdown そのものではなく CSS 側の設定に依存します。

英語のテキストも混ぜてみます。The quick brown fox jumps over the lazy dog. これはパングラムと呼ばれる、すべてのアルファベットを含む英文です。
