## なぜ Astro なのか

日記を書くときに欲しいのは、派手な機能ではなく、**書いたものがそのまま残る**という安心感だ。Astro はビルド時に HTML を生成するので、データベースもサーバーも要らない。

```bash
pnpm create astro@latest
pnpm dev
```

Markdown を保存するだけでページが増えていく。この単純さが、長く続けるためにはいちばん大事だと思っている。

## コンテンツはディレクトリで分ける

```text
src/content/
├─ daily/   日記
├─ post/    長めの記事
└─ pages/   独立したページ
```

日記と記事を最初から分けておくと、一覧の並びや RSS の扱いを後から変えやすい。

## 静的に作るということ

動的な仕組みを持たないぶん、できることは限られる。そのかわり、十年前の記事も同じ速さで開ける。積み重ねるほど価値が出る種類のサイトには、ちょうどいい。

## まとめ

- 書きたいことに集中できる
- 出力がシンプルで、どこにでも置ける
- 壊れにくい

凝った仕組みより、明日も開けるサイトでありたい。
